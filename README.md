# Philly P’arriba GitHub Pages site

## Files
- `index.html`: main landing page
- `connect.html`: Code of Conduct acknowledgement step before WhatsApp
- `styles.css`: all design and mobile styling
- `script.js`: automatic copyright year
- `assets/`: supplied logos

## Publish with GitHub Pages
1. Create a GitHub repository. For the cleanest address, name it `YOUR-USERNAME.github.io`. Otherwise, use a name such as `philly-parriba`.
2. Upload the contents of this folder to the repository root. Keep the filenames and `assets` folder structure unchanged.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will display the published address in the Pages settings.

## Before publishing
- Replace the placeholder Code of Conduct text in `connect.html` with a link to the final Code of Conduct.
- The current checkbox is not stored. For auditable acknowledgement, use Google Forms or Microsoft Forms and place the WhatsApp invite on the form confirmation screen.
- Check the class day, time, donation wording, and location language.
- Test every link on a phone before printing the QR code or programming an NFC card.
- Keep the WhatsApp invite current. Group invitation links can be reset.

## Editing colors
At the top of `styles.css`, change `--pink`, `--teal`, `--yellow`, or the other color variables.
